# SAP integrations

First implementation priority. Initial scope includes all three products:

- [S/4HANA](s4hana/README.md)
- [ECC](ecc/README.md)
- [Business One](business-one/README.md)

Each product needs its own adapter specification for submitting invoice data to the common e-UBL21 API. Additional SAP products may be added later. Status: planned.
